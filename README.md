# R Observatory feedback

Public feedback and issue tracker for [R Observatory](https://r-observatory.thecoatlessprofessor.com/), which tracks what is happening on CRAN and Bioconductor: the incoming queue, package changes, download trends across every major channel, code metrics, test coverage, and metadata.

The site's source is not public, so this is where everything about R Observatory is tracked: the site, the data, and the pipelines behind them.

## File an issue

- [Report a bug](https://github.com/r-observatory/feedback/issues/new?template=1-bug.yml) if the site is broken.
- [Report a data issue](https://github.com/r-observatory/feedback/issues/new?template=2-data.yml) if a number, a package, or a date looks wrong.
- [Request a feature](https://github.com/r-observatory/feedback/issues/new?template=3-feature.yml) for a new page, chart, metric, or export.
- [Suggest a data source](https://github.com/r-observatory/feedback/issues/new?template=4-source.yml) for a mirror or registry we should track.
- [Report a documentation issue](https://github.com/r-observatory/feedback/issues/new?template=5-documentation.yml) if something is wrong, missing, or confusing.
- [Ask a question](https://github.com/r-observatory/feedback/issues/new?template=6-question.yml) about anything else.

Security vulnerabilities do not belong in a public tracker. Email support@caffeinatedmath.com instead.
